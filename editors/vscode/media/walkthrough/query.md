# Connect and run a query

Click a process in the **Processes** view to connect; the status bar shows
the connection. Then, in a q file:

| Key | Runs |
| --- | --- |
| `Ctrl+Q` | the current line |
| `Ctrl+R` | the selection |
| `Ctrl+E` | the statement the cursor is in |

The result shows in the **q-lint: query** output with the time taken, and the
**Query History** view keeps each query to rerun. With nothing connected, a
query asks which process to connect to first.
