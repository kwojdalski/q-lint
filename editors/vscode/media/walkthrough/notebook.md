# Try a notebook

A q notebook (`.qnb`) holds code and markdown cells. Each code cell runs on
the connected process and keeps its output; a cell with `/ @chart line` (or `bar`, `scatter`, `histogram`) draws
its table as a chart.

**New q Notebook** opens an untitled one with a cell to run. Save it as a
`.qnb` file to keep it, and **Export Notebook as q Script** writes its code out as a `.q`
script.
