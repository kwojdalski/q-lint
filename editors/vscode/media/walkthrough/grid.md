# Switch query mode to grid

**Switch Query Mode** (or the mode in the status bar) picks where a result
goes:

- **console**: text in the **q-lint: query** output, the default;
- **grid**: a table, dictionary or list in the **q-lint: result** panel, to
  sort, filter and copy as CSV;
- **chart**: the same rows drawn as a chart.

Switch to grid, then run `([] a:til 5; b:5?1f)` with `Ctrl+Q`.
