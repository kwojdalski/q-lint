# VS Code extension documentation

One line per page: what it holds and when to read it. The summary, setup and
settings pointer are in the [extension README](../../editors/vscode/README.md).

| page | read it to |
|---|---|
| [features.md](features.md) | find what linting, Quick Fixes, formatting, navigation, hovers and editing helpers do, and which rules report in the editor |
| [queries.md](queries.md) | find a command for managing processes, running code (keys), inspecting a process, debugging, profiling or testing |
| [processes.md](processes.md) | look up the process list file format, discovery servers, credentials, launch definitions and the per-feature `enable` switch table |
| [results.md](results.md) | find what the grid, charts, exports, dashboards and result views do |
| [notebooks.md](notebooks.md) | write `.qnb` notebooks: cell directives, file format, the shell runner, git setup |
| [torq.md](torq.md) | use TorQ gateways, logs and tickerplants |
| [databases.md](databases.md) | use the HDB browser and the partition, sym file and column tools |
| [safety.md](safety.md) | know what is sent to a process, what counts as a write, evaluation modes and Restricted Mode |
| [extension.md](extension.md) | find chat and agent tools, the local q, the common settings, troubleshooting and how to build the extension |
